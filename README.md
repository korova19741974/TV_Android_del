# Чистый Android TV

Компактный набор для осторожной очистки телевизоров **Xiaomi**, **Hisense** и **TCL** с Android TV / Google TV: инвентаризация, обратимое отключение ненужных системных пакетов, минимальный лаунчер и настройка кнопок пульта.

## Что делает проект

- читает состояние телевизора, не меняя его;
- формирует список кандидатов на отключение для проверки вручную;
- отключает только явно одобренные пакеты через `pm disable-user`, без root и без удаления APK;
- восстанавливает отключённые пакеты;
- собирает минимальный лаунчер и позволяет назначить приложения на кнопки пульта.

Не применяйте чужой список пакетов без сверки с результатом сканирования именно вашего телевизора. После работы выключите USB/сетевую/беспроводную отладку в параметрах разработчика.

## Безопасная очистка

1. На телевизоре включите отладку по сети, узнайте его IP-адрес и подключите компьютер к той же сети.
2. В PowerShell задайте адрес и сделайте только чтение:

```powershell
$env:TV_HOST = "192.168.1.50"
python tools/unified.py scan --out work\tv-scan
```

3. Создайте план. По умолчанию все строки закомментированы как кандидаты — телевизор не меняется:

```powershell
python tools/unified.py plan --scan work\tv-scan --out work\tv-plan.txt
```

4. Откройте `work\tv-plan.txt`. Оставьте только пакеты, назначение которых вам известно, и одобрьте их явно:

```powershell
python tools/unified.py plan --scan work\tv-scan --out work\tv-plan.txt `
  --keep com.google.android.youtube.tv `
  --approve com.example.package `
  --acknowledge-mismatch
```

Для Xiaomi MiTV-MZTU1 с Android 14 ближайший профиль — Xiaomi TV A Pro 2026 (MiTV-MZTU0). Это **не** точное совпадение: используйте его только как источник кандидатов и подтверждайте каждый пакет вручную.

5. Примените или отмените тот же план:

```powershell
python tools/unified.py apply work\tv-plan.txt
python tools/unified.py restore work\tv-plan.txt
```

Если пропал доступ к телевизору, не удаляйте данные и не сбрасывайте устройство: верните пакеты последней командой после повторного подключения.

## Пять–шесть приложений и кнопки пульта

Создайте конфигурацию из нужных приложений. В `--dock` укажите пакеты приложений, которые должны остаться на главном экране; `--app-key` сопоставляет код кнопки с пакетом.

```powershell
python tools/unified.py config --out work\my-tv `
  --columns 6 `
  --dock com.google.android.youtube.tv,org.xbmc.kodi,com.netflix.ninja,com.plexapp.android `
  --app-key 190:com.google.android.youtube.tv
```

Проверьте `work\my-tv\config.json`, затем отправьте его на телевизор:

```powershell
.\tools\theme.ps1 work\my-tv
```

Чтобы установить лаунчер с обработкой кнопок, сначала проверьте работу настоящими кнопками пульта, затем выполните:

```powershell
python tools/unified.py install --input-key-service --home-key-service
```

Не включайте обработчики кнопок вслепую: некоторые производители по-разному передают Home, App и мультимедийные кнопки. Для поиска кода используйте `tools/tv.py 'getevent -l'`, нажимая физическую кнопку на пульте.
