# Чистый Android TV

Простая программа для настройки Android TV и Google TV. Она подключается к телевизору, показывает приложения, устанавливает APK с компьютера, настраивает главный экран и кнопки пульта.

## Что делает проект

- показывает установленные приложения;
- устанавливает APK-файлы с компьютера;
- добавляет выбранные приложения на главный экран;
- меняет фон и порядок приложений;
- настраивает кнопки пульта;
- позволяет безопасно отключать ненужные системные приложения и вернуть их обратно.

Не применяйте чужой список пакетов без сверки с результатом сканирования именно вашего телевизора. После работы выключите USB/сетевую/беспроводную отладку в параметрах разработчика.

## Быстрый старт через окно программы

Запустите файл `desktop\start-clean-your-tv.bat`. В окне программы можно подключить телевизор, выбрать приложения, установить APK и сохранить настройки. Командная строка для обычного использования не нужна.

Чтобы установить приложение, нажмите **«Выбрать APK на компьютере»**, укажите файл `.apk`, дождитесь установки, отметьте новое приложение в списке и нажмите **«Сохранить настройки на ТВ»**. APK должен содержать запускаемый экран для Android TV; служебные APK без значка в списке лаунчера не появятся.

Для работы компьютеру и телевизору нужно быть в одной сети. На телевизоре один раз включите отладку по сети и подтвердите запрос «Разрешить отладку».

## Запуск вручную

1. На телевизоре включите параметры разработчика и **отладку по сети / ADB debugging**. Подтвердите запрос на доверие к компьютеру. Компьютер и телевизор должны быть в одной сети.
2. При первом запуске подготовьте локальное окружение:

```powershell
python -m venv tools\venv
.\tools\venv\Scripts\python.exe -m pip install -r tools\requirements.txt
```

3. На компьютере укажите IP-адрес телевизора:

```powershell
$env:TV_HOST = "192.168.1.50"
```

4. Запустите мастер. Он сам считает модель и список запускаемых приложений, затем предложит выбрать их номерами в нужном порядке:

```powershell
python tools/unified.py setup --out work\my-tv --columns 6 --background "#101820"
```

Данные телевизора сохраняются в `work\my-tv\scan.json`; этот файл можно приложить к диалогу с ИИ для разбора, не отправляя пароли или личные файлы.

5. Отправьте созданную раскладку на телевизор и установите лаунчер:

```powershell
.\tools\theme.ps1 work\my-tv
python tools/unified.py install --input-key-service --home-key-service
```

Фон можно изменить параметром `--background "#RRGGBB"`. Расположение приложений меняется выбором их номеров в мастере; уже в лаунчере также есть ручная перестановка плиток.

### Кнопка сна

Лаунчер уже умеет привязать кнопку к действию `sleep`, которое вызывает стандартную блокировку экрана Android. Найдите код кнопки, нажимая её при запущенной команде `tools/tv.py 'getevent -l'`, затем повторите мастер, например:

```powershell
python tools/unified.py setup --out work\my-tv --sleep-key 183
```

Перед использованием ночью проверьте это с запущенным видео: Android предоставляет приложению блокировку экрана, но сохранение звука после неё зависит от прошивки телевизора и самого приложения. Если звук останавливается, используйте действие `screensaver`: оно не выключает подсветку, зато не переводит телевизор в сон.

## Безопасная очистка

1. На телевизоре включите отладку по сети, узнайте его IP-адрес и подключите компьютер к той же сети.
2. В PowerShell задайте адрес и сделайте только чтение:

```powershell
$env:TV_HOST = "192.168.1.50"
python tools/unified.py scan --out work\tv-scan
```

3. Создайте план. По умолчанию все строки закомментированы как кандидаты — телевизор не меняется:

```powershell
python tools/unified.py plan --scan work\tv-scan --out work\tv-plan.txt
```

4. Откройте `work\tv-plan.txt`. Оставьте только пакеты, назначение которых вам известно, и одобрьте их явно:

```powershell
python tools/unified.py plan --scan work\tv-scan --out work\tv-plan.txt `
  --keep com.google.android.youtube.tv `
  --approve com.example.package `
  --acknowledge-mismatch
```

Для Xiaomi MiTV-MZTU1 с Android 14 ближайший профиль — Xiaomi TV A Pro 2026 (MiTV-MZTU0). Это **не** точное совпадение: используйте его только как источник кандидатов и подтверждайте каждый пакет вручную.

5. Примените или отмените тот же план:

```powershell
python tools/unified.py apply work\tv-plan.txt
python tools/unified.py restore work\tv-plan.txt
```

Если пропал доступ к телевизору, не удаляйте данные и не сбрасывайте устройство: верните пакеты последней командой после повторного подключения.

## Пять–шесть приложений и кнопки пульта

Создайте конфигурацию из нужных приложений. В `--dock` укажите пакеты приложений, которые должны остаться на главном экране; `--app-key` сопоставляет код кнопки с пакетом.

```powershell
python tools/unified.py config --out work\my-tv `
  --columns 6 `
  --dock com.google.android.youtube.tv,org.xbmc.kodi,com.netflix.ninja,com.plexapp.android `
  --app-key 190:com.google.android.youtube.tv
```

Проверьте `work\my-tv\config.json`, затем отправьте его на телевизор:

```powershell
.\tools\theme.ps1 work\my-tv
```

Чтобы установить лаунчер с обработкой кнопок, сначала проверьте работу настоящими кнопками пульта, затем выполните:

```powershell
python tools/unified.py install --input-key-service --home-key-service
```

Не включайте обработчики кнопок вслепую: некоторые производители по-разному передают Home, App и мультимедийные кнопки. Для поиска кода используйте `tools/tv.py 'getevent -l'`, нажимая физическую кнопку на пульте.
