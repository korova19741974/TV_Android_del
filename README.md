# Чистый Android TV

Программа для Windows, которая помогает настроить главный экран телевизора через пульт.

С её помощью можно:

- оставить на главном экране до шести нужных приложений;
- установить приложение на телевизор из APK-файла на компьютере;
- выбрать обои или цвет фона;
- включить или выключить время и дату;
- показать погоду для Санкт-Петербурга;
- изменить порядок приложений;
- назначить кнопку для выключения экрана.

Интерфейс программы и лаунчера — на русском языке. Для обычного использования не нужно вводить команды.

## Что понадобится

- компьютер с Windows;
- телевизор или приставка Xiaomi с Android TV / Google TV;
- компьютер и телевизор в одной локальной сети: по Wi-Fi или Ethernet;
- включённая на телевизоре отладка по сети.

Для первого запуска нужен Python 3 и интернет: программа один раз загружает небольшие компоненты для подключения. Для кнопки «Установить лаунчер» дополнительно нужны Android Studio или JDK 17+ и Android SDK.

Сборка рассчитана на Xiaomi Mi Box и телевизоры Xiaomi с Android/Google TV 14. Работа других моделей не гарантируется.

## Как пользоваться

### 1. Подключите телевизор

1. На телевизоре откройте настройки.
2. Откройте раздел «О телевизоре».
3. Несколько раз нажмите на пункт «Сборка», пока не появится сообщение о режиме разработчика.
4. В настройках разработчика включите обычную «Отладку по сети» или «ADB debugging».
5. Запишите IP-адрес телевизора. Он указан в настройках сети.
6. На компьютере откройте файл `desktop\start-clean-your-tv.bat`.
7. Введите IP-адрес и нажмите «Подключить и проверить».
8. На телевизоре подтвердите разрешение для компьютера.

Телевизор и компьютер должны быть подключены к одной локальной сети. Если телевизор показывает только экран «Беспроводная отладка» с кодом сопряжения, это другой режим Android: сначала нужно включить обычный ADB TCP на порту 5555. После настройки отладку по сети лучше выключить.

### 2. Выберите приложения

После подключения программа покажет приложения, которые можно запустить на телевизоре.

1. Отметьте от одного до шести приложений, которые должны быть закреплены в доке.
2. Исходный порядок дока соответствует порядку строк в списке.
3. Если приложение установлено, но его нет в списке, нажмите «Обновить список».

В окне программы можно включить автоматическую сортировку дока. Тогда чаще используемые приложения будут перемещаться ближе к началу. При включённой автосортировке порядок может измениться по истории запусков. Ручной порядок, заданный через меню лаунчера, имеет приоритет.

### 3. Установите приложение из APK

1. Нажмите «Выбрать APK на компьютере».
2. Выберите файл с окончанием `.apk`.
3. Дождитесь сообщения об успешной установке.
4. Обычно приложение появится в списке автоматически; если его нет, нажмите «Обновить список».
5. Отметьте установленное приложение.
6. Нажмите «Сохранить настройки на ТВ».

Устанавливайте APK только из источников, которым доверяете. Лучше выбирать версии с поддержкой Android TV и пульта. Обычное приложение для телефона может установиться, но не иметь удобного управления с телевизора.

### 4. Настройте внешний вид

В разделе «Простые настройки» можно:

- выбрать цвет фона;
- выбрать обои с компьютера;
- убрать обои;
- показать или скрыть время;
- показать или скрыть дату;
- изменить город для погоды.

По умолчанию используется город «Санкт-Петербург, Россия». Если поле города оставить пустым, погода не будет показываться. Для погоды телевизору нужен интернет.

После изменений нажмите «Сохранить настройки на ТВ».

### 5. Установите главный экран

Нажмите «Установить лаунчер» и дождитесь окончания установки. Если телевизор спросит, какой главный экран использовать, выберите CleanYourTV.

После этого кнопка Home на пульте будет открывать новый главный экран. На нём будут только выбранные приложения, время, дата и необходимые элементы управления.

## Управление пультом

- стрелки — переход между приложениями и кнопками;
- OK — запуск выбранного приложения;
- долгое нажатие OK на приложении — меню приложения;
- в меню приложения можно переместить его или открыть сведения;
- кнопка «Настройки» — настройки телевизора;
- удерживание OK на кнопке «Настройки» открывает настройки самого лаунчера.

Настройки лаунчера сделаны крупными строками и работают без мыши.

## Выключение экрана одной кнопкой

Функция позволяет выключить экран, пока звук продолжает воспроизводиться.

1. Узнайте код нужной кнопки пульта у производителя или из инструкции к пульту.
2. Введите этот код в поле «Код кнопки сна».
3. Сохраните настройки и установите обработчик кнопок вместе с лаунчером.
4. Проверьте функцию сначала при включённом видео.

После выключения экран должен снова включаться нажатием любой кнопки. Поведение звука зависит от прошивки телевизора и самого приложения: некоторые телевизоры могут остановить воспроизведение при блокировке экрана.

## Если подключение не работает

Проверьте по порядку:

1. компьютер и телевизор подключены к одной локальной сети;
2. IP-адрес введён без лишних пробелов;
3. на телевизоре включена отладка по сети;
4. запрос доверия к компьютеру подтверждён;
5. телевизор не находится в гостевой сети, которая запрещает устройствам видеть друг друга.

Если приложение установилось, но не появляется в списке, нажмите «Обновить список». Программа показывает только приложения с экраном, который можно открыть на Android TV.

## Безопасность

Программа подключается к телевизору по ADB и выполняет выбранные пользователем действия. Установка лаунчера также назначает его главным экраном и отключает распознанный штатный лаунчер; скрипт оставляет путь восстановления, если передача управления не завершилась. APK передаётся на телевизор напрямую с компьютера. Не устанавливайте неизвестные файлы.

Не удаляйте системные приложения без уверенности в их назначении: это может отключить звук, Wi-Fi, пульт или запуск телевизора. После настройки выключите отладку по сети.
