# Чистый Android TV

Программа для Windows и macOS помогает настроить главный экран телевизора через пульт.

С её помощью можно:

- оставить на главном экране до 12 нужных приложений;
- установить приложение на телевизор из APK-файла на компьютере;
- выбрать обои или цвет фона;
- включить или выключить время и дату;
- показать погоду для Санкт-Петербурга;
- изменить порядок приложений;
- назначить кнопку для выключения экрана.

Интерфейс программы и лаунчера — на русском языке. Для обычного использования не нужно вводить команды.

## Скачать программу

1. Откройте страницу [последней версии](https://github.com/korova19741974/TV_Android_del/releases/latest).
2. В разделе **Assets** скачайте архив `CleanYourTV-windows-*.zip`.
3. Распакуйте архив в обычную папку.
4. Откройте папку `CleanYourTV` и запустите `CleanYourTV.exe`.

Копировать или запускать один EXE отдельно нельзя: рядом с ним находятся файлы, необходимые для подключения и установки лаунчера.

## Что понадобится

- компьютер с Windows или Mac;
- телевизор или приставка Xiaomi с Android TV / Google TV;
- компьютер и телевизор в одной локальной сети: по Wi-Fi или Ethernet;
- включённая на телевизоре отладка по сети;
- интернет при первом запуске.

Python устанавливать не нужно: он уже находится в скачанном комплекте. При первой установке лаунчера программа проверит JDK 17 и Android SDK и автоматически установит только недостающие компоненты. Windows может показать запрос на разрешение установки.

Сборка рассчитана на Xiaomi Mi Box и телевизоры Xiaomi с Android/Google TV 14. Работа других моделей не гарантируется.

## Как пользоваться

### 1. Подключите телевизор

1. На телевизоре откройте настройки.
2. Откройте раздел «О телевизоре».
3. Несколько раз нажмите на пункт «Сборка», пока не появится сообщение о режиме разработчика.
4. В настройках разработчика включите обычную «Отладку по сети» или «ADB debugging».
5. Запишите IP-адрес телевизора. Он указан в настройках сети.
6. На компьютере запустите `CleanYourTV.exe` из распакованной папки.
7. Введите IP-адрес и нажмите «Подключить и проверить».
8. На телевизоре подтвердите разрешение для компьютера.

Телевизор и компьютер должны быть подключены к одной локальной сети. Если телевизор показывает только экран «Беспроводная отладка» с кодом сопряжения, это другой режим Android: сначала нужно включить обычный ADB TCP на порту 5555. После настройки отладку по сети лучше выключить.

### 2. Выберите приложения

После подключения программа покажет приложения, которые можно запустить на телевизоре.

1. Отметьте от одного до 12 приложений, которые должны быть на главном экране.
2. Исходный порядок дока соответствует порядку строк в списке.
3. Если приложение установлено, но его нет в списке, нажмите «Обновить список».

Последний введённый адрес, выбранные параметры и настройки лаунчера сохраняются автоматически. При следующем запуске их не нужно вводить заново.

В окне программы можно включить автоматическую сортировку дока. Тогда чаще используемые приложения будут перемещаться ближе к началу. При включённой автосортировке порядок может измениться по истории запусков. Ручной порядок, заданный через меню лаунчера, имеет приоритет.

### 3. Установите приложение из APK

1. Нажмите «Выбрать APK на компьютере».
2. Выберите один или несколько файлов с окончанием `.apk`.
3. Дождитесь установки всех файлов: программа покажет номер текущего APK.
4. Обычно приложения появятся в списке автоматически; если их нет, нажмите «Обновить список».
5. Отметьте нужные приложения.
6. Нажмите «Сохранить настройки на ТВ».

Устанавливайте APK только из источников, которым доверяете. Лучше выбирать версии с поддержкой Android TV и пульта. Обычное приложение для телефона может установиться, но не иметь удобного управления с телевизора.

### 4. Настройте внешний вид

В разделе «Простые настройки» можно:

- выбрать цвет фона;
- выбрать обои с компьютера;
- убрать обои;
- показать или скрыть время;
- показать или скрыть дату;
- изменить город для погоды.

По умолчанию используется город «Санкт-Петербург, Россия». Если поле города оставить пустым, погода не будет показываться. Для погоды телевизору нужен интернет.

После изменений нажмите «Сохранить настройки на ТВ».

### 5. Установите главный экран

Нажмите «Установить лаунчер» и дождитесь окончания установки. Если телевизор спросит, какой главный экран использовать, выберите CleanYourTV.

После этого кнопка Home на пульте будет открывать новый главный экран. На нём будут только выбранные приложения, время, дата и необходимые элементы управления.

## Amnezia VPN

Если на телевизоре установлена Amnezia, на главном экране появится кнопка с её состоянием:

- зелёная «Amnezia включена» — VPN работает;
- красная «Amnezia выключена» — VPN не подключён.

Нажмите ОК, чтобы открыть Amnezia. Удерживайте ОК, чтобы открыть сведения о приложении. В этом разделе телевизора можно отключить автоматическую очистку или ограничение фоновой работы, если такие пункты есть в прошивке.

Обычный выход кнопкой Home не отключает VPN. Принудительная остановка Amnezia в системных настройках всё равно остановит VPN — это ограничение Android.

## Управление пультом

- стрелки — переход между приложениями и кнопками;
- OK — запуск выбранного приложения;
- долгое нажатие OK на приложении — меню приложения;
- в меню приложения можно переместить его или открыть сведения;
- кнопка «Настройки» — настройки телевизора;
- удерживание OK на кнопке «Настройки» открывает настройки самого лаунчера.

Настройки лаунчера сделаны крупными строками и работают без мыши.

## Выключение экрана одной кнопкой

Можно назначить эту функцию на любую кнопку пульта, например Netflix. Код искать и вводить вручную не нужно.

1. Сначала установите лаунчер и обработчики кнопок.
2. В программе на компьютере нажмите «Настройка кнопки сна».
3. Когда появится сообщение, нажмите и удерживайте нужную кнопку на пульте примерно одну секунду.
4. Программа сама определит кнопку и покажет её название.
5. Нажмите «Сохранить настройки на ТВ».

После этого долгое нажатие выбранной кнопки выключает экран, а звук может продолжать играть. Нажатие любой кнопки обычно снова включает экран. Сначала проверьте функцию на включённом видео: некоторые прошивки или приложения останавливают звук при блокировке экрана.

Не выбирайте для этой функции кнопку питания, Home, OK или кнопки громкости. Если телевизор не обнаружил кнопку, установите обработчики кнопок ещё раз и повторите настройку с другой кнопкой.

## Если подключение не работает

Проверьте по порядку:

1. компьютер и телевизор подключены к одной локальной сети;
2. IP-адрес введён без лишних пробелов;
3. на телевизоре включена отладка по сети;
4. запрос доверия к компьютеру подтверждён;
5. телевизор не находится в гостевой сети, которая запрещает устройствам видеть друг друга.

Если приложение установилось, но не появляется в списке, нажмите «Обновить список». Программа показывает только приложения с экраном, который можно открыть на Android TV.

## Безопасность

Программа подключается к телевизору по ADB и выполняет выбранные пользователем действия. Установка лаунчера также назначает его главным экраном и отключает распознанный штатный лаунчер; скрипт оставляет путь восстановления, если передача управления не завершилась. APK передаётся на телевизор напрямую с компьютера. Не устанавливайте неизвестные файлы.

Не удаляйте системные приложения без уверенности в их назначении: это может отключить звук, Wi-Fi, пульт или запуск телевизора. После настройки выключите отладку по сети.

## Если у вас Mac

Скачайте DMG-файл для своей модели Mac:

- `arm64` — Mac с Apple Silicon (M1, M2, M3, M4);
- `x86_64` — Mac с процессором Intel.

Откройте DMG и перетащите `CleanYourTV` в папку «Программы». При первом запуске macOS может показать предупреждение: нажмите правой кнопкой на приложение, выберите «Открыть», затем подтвердите запуск.

Mac-версия уже содержит готовый APK лаунчера и не требует JDK, Android SDK или PowerShell для обычной установки. Нужны только телевизор в той же сети и включённая отладка по сети.

Если DMG недоступен, лаунчер можно установить на Mac напрямую из исходного кода:

1. Установите [Homebrew](https://brew.sh/) и Python 3.
2. Установите JDK 17 и Android SDK Platform Tools:

   ```bash
   brew install --cask temurin@17
   brew install android-platform-tools
   ```

3. Скачайте исходный код проекта с GitHub и откройте Terminal в папке проекта.
4. Создайте окружение и установите необходимые модули:

   ```bash
   python3 -m venv tools/venv
   tools/venv/bin/python -m pip install -r tools/requirements.txt
   ```

5. Включите на телевизоре отладку по сети, узнайте его IP-адрес и один раз подтвердите подключение:

   ```bash
   export TV_HOST=192.168.1.50
   tools/venv/bin/python -I tools/tv.py 'getprop ro.build.version.sdk'
   ```

6. Установите лаунчер и помощники кнопок:

   ```bash
   TV_HOST=192.168.1.50 INPUT_KEY_SERVICE=1 HOME_KEY_SERVICE=1 \
     bash launcher/build-and-install.sh
   ```

Замените `192.168.1.50` на IP-адрес своего телевизора. После установки нажмите Home на пульте.

После настройки выключите отладку по сети на телевизоре.
